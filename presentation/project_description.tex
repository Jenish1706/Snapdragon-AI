\begin{abstract}
Deploying small language models on heterogeneous Snapdragon mobile and PC platforms requires navigating distinct trade-offs across three compute engines: CPU, Adreno GPU, and Hexagon NPU. Published benchmarks on Snapdragon SoCs demonstrate that no single processor dominates all phases: the Hexagon NPU achieves up to $5\times$ faster prefill, yet decodes up to $2.5\times$ slower than CPU or GPU cores due to memory-bandwidth and sequence serialization constraints. Existing optimizers treat compute unit selection, weight precision, and low-rank compression as disconnected decisions.

\textbf{Ising-Edge} is a unified, open-source combinatorial optimization framework that jointly determines compute unit placement (CPU, GPU, NPU), weight precision (Q4\_0, Q8\_0), and low-rank compression levels across every transformer block simultaneously. By mapping hardware latency profiles, synchronization costs, and compound cross-layer perplexity interactions into a single Quadratic Unconstrained Binary Optimisation (QUBO)\,/\,Ising Hamiltonian, Ising-Edge generates globally optimal execution plans emitted as native \texttt{llama.cpp} configuration flags.

Empirical evaluations on Qwen3-0.6B (WikiText-2, 584 chunks) establish that: (1)~compression damage is super-additive across layers ($+275.6\%$ measured vs.\ $+57.8\%$ linear sum); (2)~pairwise QUBO plans outperform random allocations by 91.61~percentage points at matched byte budgets; (3)~Matrix Product Operators achieve 65~pp lower degradation than SVD in deep composition; and (4)~discrete 1-swap descent reaches exact global optima in under 5\,ms.
\end{abstract}

No single engine dominates: the NPU delivers up to $5\times$ faster prefill on phones, but on PCs the CPU decodes more than $2\times$ faster than the NPU. A static assignment of the entire model to a single processor leaves substantial throughput and energy efficiency unrealized. Ising-Edge addresses this challenge by formulating the complete hardware execution problem as a unified combinatorial optimization.

\section{The Ising-Edge Framework}
%----------------------------------------------------------------------

\subsection{SnapTwin Performance Model}
SnapTwin models on-device execution time by decomposing inference into prefill and autoregressive decode phases across each hardware unit $u \in \{\text{CPU}, \text{GPU}, \text{NPU}\}$. Autoregressive decode latency is governed by the memory-bandwidth roofline:
\begin{equation}
\hat{T}_{\text{decode}}(l, u, q, r) = \frac{\text{Bytes}(l, q, r)}{\eta_{u} \cdot B_u} + \tau_{u}
\label{eq:decode}
\end{equation}
where $B_u$ is effective bus bandwidth, $\eta_u$ is operational bus efficiency, $\text{Bytes}(l,q,r)$ is tensor size under precision $q$ and rank ratio $r$, and $\tau_u$ is fixed kernel overhead. Prefill is modeled via compute-intensity saturation curves, and inter-unit transfers incur synchronization overhead $C_{\text{sync}}(u_l, u_{l+1})$.

\subsection{QUBO Formulation}
Let $x_{l,u,q,r} \in \{0,1\}$ indicate whether layer $l$ is assigned to unit $u$, precision $q$, and compression ratio $r$. The global objective minimizes:
\begin{equation}
\mathcal{H}(x) = \sum_i c_i x_i + \sum_{i < j} Q_{ij} x_i x_j
\label{eq:qubo}
\end{equation}
where $c_i$ encodes isolated latency plus accuracy degradation $\alpha_i \Delta\text{PPL}_i$, and $Q_{ij}$ encodes hardware switching costs and non-linear cross-layer coupling penalties $J_{ij}$, subject to one-hot allocation $\sum_{u,q,r} x_{l,u,q,r} = 1$ and memory budget $\sum \text{Bytes}(i)\, x_i \le M_{\text{budget}}$.

The necessity of the quadratic coupling terms is proven mathematically: in a transformer residual stream, the error $e_l = \tilde{x}_l - x_l$ under compressed weights propagates as:
\begin{equation}
e_{l+1} = \bigl(I + J_{F_l}(x_l) + J_{\Delta F_l}(x_l)\bigr)\, e_l + \Delta F_l(x_l)
\label{eq:error}
\end{equation}
The bilinear cross-term $J_{\Delta F_l} e_l$ couples incoming representation drift with weight distortion, causing super-exponential degradation through non-linear SwiGLU activations.

\subsection{Combinatorial Solvers}
Ising-Edge employs two primary solvers that achieve exact global optima:
\begin{itemize}[nosep]
\item \textbf{CP-SAT} (Google OR-Tools): Integer programming branch-and-cut with lazy no-good cuts.
\item \textbf{Greedy 1-Swap Descent}: Operates directly on the constrained feasible manifold $\mathcal{S}_K = \{x \in \{0,1\}^n \mid \sum x_i = K\}$, evaluating candidate swaps in $O(1)$ amortized time via:
\end{itemize}
\begin{equation}
\Delta E_{i \to j} = (c_j - c_i) + 2\sum_{k \neq i,j}(Q_{jk} - Q_{ik})x_k - 2Q_{ij}
\label{eq:swap}
\end{equation}
An active closed-loop surrogate (rank-6 Factorization Machine fitted to $\ln(\text{PPL}/\text{PPL}_{\text{dense}})$) iteratively refines plans via a \emph{Measure $\to$ Fit $\to$ Solve} loop.

\section{Key Results}
%----------------------------------------------------------------------

All evaluations use Qwen3-0.6B on WikiText-2 (512 context, 584 chunks). Dense baseline: PPL\,=\,21.884.

\paragraph{Super-Additivity of Compression Damage.}
Compressing 24 middle MLP blocks (layers 2--25) at keep 0.8: the linear sum of single-layer damages predicts $+57.78\%$, but measured degradation is $+275.6\%$---a 4.8$\times$ underestimation. This confirms that single-layer planning is mathematically invalid.

\paragraph{Combinatorial Superiority at Matched Bytes.}
At $K\!=\!18$ MLPs compressed (keep 0.8), the pairwise QUBO plan achieves $+66.9\%$ $\Delta$PPL vs.\ random allocation at $+158.5\%$, a \textbf{91.61~pp advantage} (paired bootstrap 4,000 resamples: 95\% CI $[-94.03, -89.04]$~pp, $p < 10^{-4}$).

\paragraph{Tensor Network Scaling (MPO vs.\ SVD).}
Across 24 layers at keep 0.9 with matched parameters: 3-core MPO achieves PPL~39.05 ($+78.4\%$) vs.\ activation-aware SVD at PPL~53.17 ($+143.0\%$)---an approximately 65~pp advantage. MPO distributes truncation error isotropically across tensor cores, canceling destructively along the residual stream.

\section{Deployment \& Open-Source Stack}
%----------------------------------------------------------------------

Ising-Edge is built entirely on permissively licensed open-source technologies:
\begin{itemize}[nosep]
\item \textbf{Base Model:} Qwen3-0.6B / 1.7B / 4B (Apache-2.0 license).
\item \textbf{Inference Runtime:} \texttt{llama.cpp} (MIT license) with native backends for Snapdragon CPU, Adreno GPU (OpenCL), and Hexagon NPU (QNN/HTP).
\end{itemize}
Optimal plans emit standard \texttt{llama.cpp} CLI flags (\texttt{-dev}, \texttt{-ot}, \texttt{-ctk}, \texttt{-ctv}) for immediate zero-code deployment on Snapdragon PCs and mobile devices without modifying host OS drivers or runtime binaries. The full codebase includes 56 unit tests with 100\% pass rate.

\section{Conclusion}
%----------------------------------------------------------------------

Ising-Edge demonstrates that on-device language model acceleration on Snapdragon architectures cannot be achieved through isolated, greedy choices. By uniting hardware execution profiling, cross-layer interaction modeling, and joint combinatorial optimization into a single quadratic formulation, Ising-Edge delivers: (1)~rigorous protection against super-additive compression collapse; (2)~verified 91.6~pp accuracy gains at matched byte budgets; (3)~scalable multi-layer tensor network compression with Matrix Product Operators; and (4)~sub-millisecond combinatorial plan synthesis for real-time edge deployment.
